Agent Documentation Demo

How an AI agent reads OSSYREL data, what each file means, and the rules that govern agent actions. Also see skill.md (plain-text version) and agent/index.html.

1 · Overview

OSSYREL — The Hash Ledger — is a collection of 5,000 ERC-721 Node NFTs on BNB Chain (Chain ID 56). Five classes share one global supply. Each node carries hash rate and shares; shares accrue OSR (BEP-20) daily at the current Era rate. The contract is PENDING — not deployed, so every number on this site is DEMO simulation data.

3 · Data model

collection.json

name, collection, tagline, chain (name + chainId 56), standard ("ERC-721"), maxSupply (5000), tiers[] (id, name, priceBnb, hashRateMh, shares, maxPerWallet), osr (symbol, standard "BEP-20", maxSupply 1,000,000,000, miningAllocation 700,000,000, reserveAllocation 300,000,000, era1PerSharePerDay 10, eraDays 30, eraNewSharesTrigger 150000), contract (status "PENDING", address null), status ("DEMO").

api/stats.json

status ("DEMO"), minted, maxSupply, totalHashRateMh, totalShares, currentEra, eraRateOsrPerSharePerDay, osrDistributed, contract (status "PENDING", address null).

api/eras.json

currentEra, transition (days 30, newShares 150000, rule "whichever first"), eras[] (era number, rate, status), note (simulation disclaimer).

api/nodes.json

status ("DEMO"), nodes[] (tokenId, tier, priceBnb, hashRateMh, shares, status, owner "DEMO"). No real tokens exist yet.

4 · The mint flow (when live)

1 · Read

Fetch collection.json and api/stats.json. Confirm a contract address is present and verified. Today it is not — status is PENDING.

2 · Prepare

Build the mint request from the tier table: class, quantity, exact BNB price. Show the user the exact amount before anything is signed.

3 · Authorize

The user signs in their own wallet. The agent never signs, never holds keys, and never proceeds without explicit authorization.

5 · Rules for agents

  • Read-only by default. Prepare requests; never execute without explicit wallet authorization.
  • Never ask for a seed phrase, private key, or recovery phrase.
  • Label DEMO data as DEMO. Never present demo figures as live earnings.
  • Do not invent a contract address, transaction hash, or live statistic. If it is missing, say so.
  • Era rates are simulation parameters, not a promise of profit or return.
