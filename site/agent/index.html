Agent Interface Demo Contract pending

This page is for AI agents acting on behalf of a user. It exposes OSSYREL's spec and DEMO state as plain files an agent can fetch and read — no authentication, no execution.

Agent rule: an agent may only read data from this interface and prepare a transaction request for the user. No transaction executes without the user's explicit wallet authorization. The agent must never ask for a seed phrase or private key. There is no contract to call yet — every endpoint below is DEMO data.

How an Agent Mints (when live)

1 · Read

Fetch api/stats.json and collection.json. Confirm the contract address is present and verified — today it is not (PENDING).

2 · Prepare

Build the mint request from the spec: class, quantity, exact price from the tier table. Show the user the exact amount before anything is signed.

3 · Authorize

The user signs in their own wallet. The agent never signs, never holds keys, and never proceeds without that explicit authorization.

Simulation, not a promise: Era rates and the halving schedule are design parameters of the OSSYREL simulation, not a guarantee of profit or return. An agent must not present demo figures as live earnings.
